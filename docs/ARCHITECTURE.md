# 架构说明

```text
家庭App / 管理端 / 语音助手
            ↓
     家庭与权限领域层
            ↓
空间 ─ 设备能力 ─ 场景 ─ 自动化 ─ 告警 ─ 能耗
            ↑
Matter/Zigbee/Wi-Fi 网关适配器
```

设备在领域层以“能力列表+状态”表达，不把厂商协议泄漏到业务代码。网关负责把 Matter Cluster、Zigbee Cluster 或厂商属性转换为标准能力事件。自动化规则消费幂等设备事件，匹配后调用同一场景执行逻辑。

生产部署建议按家庭ID分区，并对设备命令使用异步确认、超时和重试；高风险门锁与安防命令需要二次鉴权和短期令牌。
